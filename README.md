# CSS-Auth-Navigation
A modern, responsive, glassmorphism-inspired Login & Signup authentication interface built using pure HTML and CSS. Featuring dynamic dark aesthetic overlays, crisp typography, and navigation transitions for a sleek user experience.

🎨 UI Preview

The design features:

Bold Contrast Styling: Standout red primary headings with clean white serif/sans-serif typography.

Glassmorphism Aesthetic: Translucent form card container set against a rich background wallpaper/gradient.

Rounded Input Fields: Soft, dark input fields with styled placeholder text.

Interactive Elements:

Username & Password fields

"Remember me" checkbox selection

"Forgot password?" quick link

Accent action buttons (login / register)

Smooth navigation toggle link to switch between Login and Register views

✨ Key Features

Pure HTML5 & CSS3: No external JavaScript frameworks required for styling.

Glassmorphism / Frosted Glass UI: Utilizes CSS backdrop-filter and semi-transparent background layers.

Fully Responsive: Adapts cleanly across screens, tablets, and desktop devices.

Customizable Styles: Clean CSS rules separated into manageable style properties for easy palette switching.

🚀 Getting Started

To view and customize this project locally:

Prerequisites

A modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, or Safari).

Installation & Usage

Clone the repository:

git clone https://github.com/davecodes-ux/CSS-Auth-Navigation-.git


Navigate into the project directory:

cd CSS-Auth-Navigation-


Open the application:
Double-click index.html or run it using Live Server in VS Code.

🛠️ Customization Quick-Guide

You can easily adjust the color palette inside your style.css:

/* Custom Header Accent */
.form-title {
  color: #ff2a2a; /* Red header accent */
}

/* Glassmorphism Card Overlay */
.login-card {
  background: rgba(255, 255, 255, 0.08);
  backdrop-filter: blur(10px);
  border-radius: 20px;
}

/* Rounded Input Style */
input[type="text"], input[type="password"] {
  border-radius: 20px;
  background: rgba(0, 0, 0, 0.25);
}
